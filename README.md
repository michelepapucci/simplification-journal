# Simplification data explorer

This branch holds only the static site published with GitHub Pages. It shows READ-IT distributions and
linguistic profiles of the original–simplified pairs used to train and test the readability-controlled
simplification models, broken down by split, strategy (or targeted dimension) and control token. A selector
switches between three datasets:

- **CLiC-it 2025**: the Wikipedia sample analysed in the CLiC-it 2025 paper;
- **v0**: the CLiC-it 2026 (GFFF) training selection, fixed (`data/v0/` on `master`);
- **v1**: three target tokens per pair (`data/v1/` on `master`).

Files:

- `index.html`, `style.css`, `app.js`: the page, with no external dependencies.
- `data_clicit2025.js`, `data_v0.js`, `data_v1.js`: every number the page shows, generated by
  `scripts/build_webview_data.py` on the `master` branch.

## Regenerating the data

From a checkout of `master` with `data/v0/` and `data/v1/` built (`scripts/build_dataset_v0.py`, `scripts/build_dataset_v1.py`),
inside the `text-simplification-experiments` repository (the 2025 sample is read from its `data/sampled_final_dataset/`):

```sh
git worktree add ../simplification-journal-site gh-pages
python scripts/build_webview_data.py --out ../simplification-journal-site   # or --datasets v1 to rebuild one
cd ../simplification-journal-site
git add data_*.js && git commit -m "Regenerate webview data" && git push origin gh-pages
```

## Previewing locally

Open `index.html` directly, or serve the folder with `python -m http.server` and visit http://localhost:8000.
