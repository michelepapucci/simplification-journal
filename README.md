# Simplification data explorer

This branch holds only the static site published with GitHub Pages. It has two parts.

**Part 1, data analysis of IMPaCTS:** READ-IT distributions and linguistic profiles of the original–simplified
pairs used to train and test the readability-controlled simplification models, broken down by split, strategy
(or targeted dimension) and control token. A selector switches between six datasets:

- **CLiC-it 2025**: the Wikipedia sample analysed in the CLiC-it 2025 paper;
- **v0**: the CLiC-it 2026 (GFFF) training selection, fixed (`data/v0/` on `master`);
- **v1**: three target tokens per pair (`data/v1/` on `master`);
- **v2**: v1 plus 11,752 pairs with larger lexical drops, non-Italian pairs removed (`data/v2/` on `master`);
- **v3**: v2 with same-level base and syntax targets, so light edits get a token (`data/v3/` on `master`);
- **v4**: v3 with a syntax target on every pair whose syntax did not rise, including drops within the noise margin (`data/v4/` on `master`).

**Part 2, model generation analysis:** the two Qwen3-0.6B models trained on v1 (target tokens; source + target
tokens), the target-token models trained on v2, v3 and v4, and the CLiC-it 2026 Qwen3-0.6B, asked to simplify the test
originals to every READ-IT level below their own. Requested against achieved READ-IT (the CLiC-it 2026 curves; the
CLiC-it model and our two latest models are drawn by default, the others from the legend), per-level tables, the
joint evaluation with all three dimensions requested, and one worked example per test set (`data/v1/experiments/` on
`master`).

Files:

- `index.html`, `style.css`, `app.js`: the page, with no external dependencies.
- `data_clicit2025.js`, `data_v0.js`, `data_v1.js`, `data_v2.js`, `data_v3.js`, `data_v4.js`: every number of part 1, generated by
  `scripts/build_webview_data.py` on the `master` branch.
- `data_generation.js`: every number of part 2, generated by `scripts/build_generation_webview.py` from
  `data/v1/experiments/results/summary.json` and the models' outputs.

## Regenerating the data

From a checkout of `master` with `data/v0/` to `data/v4/` built (`scripts/build_dataset_v0.py` to `scripts/build_dataset_v4.py`),
inside the `text-simplification-experiments` repository (the 2025 sample is read from its `data/sampled_final_dataset/`):

```sh
git worktree add ../simplification-journal-site gh-pages
python scripts/build_webview_data.py --out ../simplification-journal-site   # or --datasets v1 to rebuild one
python scripts/build_generation_webview.py --out ../simplification-journal-site   # after data/v1/experiments/analyze.py
cd ../simplification-journal-site
git add data_*.js && git commit -m "Regenerate webview data" && git push origin gh-pages
```

## Previewing locally

Open `index.html` directly, or serve the folder with `python -m http.server` and visit http://localhost:8000.
