# Simplification explorer

This branch holds only the static site published with GitHub Pages
(https://michelepapucci.github.io/simplification-journal/).

The site covers readability-controlled Italian simplification with **one control token on READ-IT global**, the
LREC 2026 setup.

**Part 1, the data:** dataset g1, from the Wikipedia part of IMPaCTS. It shows the READ-IT distributions and the
linguistic profiles (Profiling-UD, with the analyses of the CLiC-it 2025 paper) of the training pairs and the test
references, by original level and control token.

**Part 2, the models:** the Qwen3-0.6B models trained on g1:
- g1 (plain);
- g1 · balanced (levels 0–70 shown equally often);
- g1 · guided (classifier-free guidance on the token), and best-of-n selection.

They are asked to simplify 1,000 test originals to every READ-IT level below their own.

`archive/multidim/` is the explorer of the earlier work with three control tokens (base, lexical, syntax; datasets
v0 to v7). Its code and data are on the `multidim-archive` branch.

Files:

- `index.html`, `style.css`, `app.js`: the page, with no external dependencies.
- `data_g1.js`: every number of part 1, generated by `scripts/build_webview_data.py` on `master`.
- `data_results.js`, `results.js`: part 2. The data is generated by `scripts/build_results_webview.py` on `master`
  from `experiments/results/summary.json` and the models' outputs.

## Regenerating the data

From a checkout of `master` with `data/g1/` built (`scripts/build_dataset_g1.py`), inside the
`text-simplification-experiments` repository:

```sh
git worktree add ../simplification-journal-site gh-pages
python scripts/build_webview_data.py --out ../simplification-journal-site
python scripts/build_results_webview.py --out ../simplification-journal-site    # after experiments/analyze.py
cd ../simplification-journal-site
git add data_*.js && git commit -m "Regenerate webview data" && git push origin gh-pages
```

## Previewing locally

Open `index.html` directly, or serve the folder with `python -m http.server` and visit http://localhost:8000.
